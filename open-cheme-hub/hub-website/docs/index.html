Running in about a minute

The templates need nothing installed beyond what you already have. The workflows ship a pinned container so a reviewer can actually rerun your analysis. 

# Starting points you can edit today
git clone https://github.com/OpenChemE/templates
cd templates
python unit_conversions.py         # self-test with worked examples
python reactor_design_skeleton.py -X 0.9 --sweep

# A reproducible pipeline, environment and all
git clone https://github.com/OpenChemE/workflows
cd workflows/snakemake
conda env create -f environment.yaml
conda activate conformer-gen
snakemake -n --cores 4             # dry run first, always

Where to start

Students

Fork templates and open the material balance notebook. Work a balance you already know how to do by hand — seeing the two agree is the fastest way to trust the tooling. Then browse the free textbooks in the chemical engineering list.

Student path →

Researchers

Start with workflows. The Snakemake pipeline and pinned Docker image give you an environment a reviewer can rerun, and the ELN template gives you a record that still makes sense in two years.

Researcher path →

Industry engineers

The process simulation and safety sections are where most people land — open alternatives to licensed tools, plus a HAZOP-style checklist for a pre-review read. The Aspen version-control guide covers working alongside what you already own.

Industry path →

Adding something takes two minutes

Find the right list and section, add one line, open the pull request. The template tells you what a reviewer will check. You don't need permission and you don't need to open an issue first. 

- [Cantera](https://cantera.org) — Object-oriented toolkit for chemical kinetics,
  thermodynamics, and transport, with reactor network solvers. `python` `c++` `matlab`

We accept anything freely usable, maintained (or complete and not needing maintenance), and genuinely useful to practitioners. We decline paywalled tools with no real free path, abandoned projects, SEO listicles, and predatory conferences. Your own project is welcome — say it's yours and hold it to the same bar.

On trust. These lists are a starting point, not a personally audited reference. Every entry is a project we can place as real, but the links have not been machine-verified end to end — a scheduled link checker runs weekly on each list and opens an issue for anything broken. If you find rot, the fastest fix is a pull request.
