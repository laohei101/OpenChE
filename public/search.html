Search everything

One box across all five lists plus the templates and workflows. Runs entirely in your browser against a JSON index — no server, no tracking, works offline once the page has loaded. The index covers around 200 of the most-reached-for entries; the lists themselves are the complete set.

How this works

assets/data/resources.json is the site's own copy of the lists. Matching is a weighted token score — name matches rank above description matches, and every token you type must appear somewhere in the record. It is deliberately not a fuzzy search: for a few hundred records, exact substring matching gives more predictable results than a similarity threshold anyone would have to tune.

Press / anywhere to jump to the search box and Escape to clear it. Deep links work too — /search.html?q=cantera runs that query on load.

Everything indexed here also lives in a plain Markdown file on GitHub. If the search is ever wrong, the list is the source of truth.
